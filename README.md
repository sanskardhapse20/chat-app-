# Realtime Chat Application Using WebSocket

## 📌 Project Overview

This project is a realtime chat application developed using Node.js, Express.js, and WebSocket technology. It allows multiple users to communicate instantly through a modern web interface.

---

# 🚀 Features

- Realtime messaging
- Multiple user support
- Online users counter
- Username system
- Modern dark UI
- Responsive design
- Fast communication using WebSocket

---

# 🛠 Technologies Used

## Frontend
- HTML
- CSS
- JavaScript

## Backend
- Node.js
- Express.js
- WebSocket (ws)
